# PRD: 오늘의 할일 (Today's To-Do) 웹페이지

- 문서 버전: v0.1 (설계 단계)
- 작성일: 2026-11-02
- 상태: 설계 완료 / 구현 전

---

## 1. 개요

### 1.1 배경
하루 단위로 해야 할 일을 빠르게 적고, 완료 여부를 체크하며, 오늘 얼마나 진행했는지 한눈에 확인할 수 있는 가벼운 웹페이지가 필요하다. 회원가입·서버 없이 브라우저만으로 바로 쓸 수 있어야 한다.

### 1.2 목표
- 3초 안에 할일 하나를 추가할 수 있다.
- 오늘의 진행률(완료/전체)을 한눈에 볼 수 있다.
- 새로고침하거나 브라우저를 다시 열어도 데이터가 유지된다.
- 날짜가 바뀌면 "오늘" 목록이 자연스럽게 새로 시작된다.

### 1.3 비목표 (이번 버전에서 하지 않는 것)
- 로그인/계정, 서버 동기화, 여러 기기 간 공유
- 반복 일정, 알림(푸시), 캘린더 연동
- 협업(다른 사람과 목록 공유)

## 2. 대상 사용자

| 페르소나 | 설명 | 핵심 니즈 |
|---|---|---|
| 직장인 | 출근 후 오늘 할 업무를 정리 | 빠른 입력, 우선순위 구분 |
| 학생 | 공부·과제 계획 관리 | 진행률 확인, 성취감 |
| 개인 사용자 | 장보기·집안일 등 생활 할일 | 간단함, 설치 없음 |

## 3. 사용자 스토리

1. 사용자로서, 입력창에 할일을 적고 Enter를 눌러 바로 추가하고 싶다.
2. 사용자로서, 할일을 체크해 완료 표시하고, 다시 체크 해제할 수 있어야 한다.
3. 사용자로서, 할일 내용을 더블클릭해 수정하고 싶다.
4. 사용자로서, 필요 없는 할일을 삭제하고 싶다.
5. 사용자로서, 중요한 할일에 우선순위(높음/보통/낮음)를 지정하고 싶다.
6. 사용자로서, 전체/진행 중/완료 필터로 목록을 나눠 보고 싶다.
7. 사용자로서, 오늘 몇 개 중 몇 개를 끝냈는지 진행률 바로 보고 싶다.
8. 사용자로서, 완료한 항목을 한 번에 정리(삭제)하고 싶다.
9. 사용자로서, 어제 못 끝낸 할일을 오늘로 가져오고 싶다.
10. 사용자로서, 드래그로 할일 순서를 바꾸고 싶다.

## 6. 화면 설계

### 6.1 레이아웃 (와이어프레임)

```
┌──────────────────────────────────────┐
│  오늘의 할일                    [🌙]  │  ← 헤더 (제목, 다크모드 토글)
│  2026년 11월 2일 (월)                 │
├──────────────────────────────────────┤
│  ▓▓▓▓▓▓▓▓▓▓░░░░░░  3 / 5 완료 (60%)  │  ← 진행률
├──────────────────────────────────────┤
│  ⚠ 어제 못 끝낸 2개가 있어요 [가져오기] [닫기] │  ← 이월 배너 (조건부)
├──────────────────────────────────────┤
│  [ 할 일을 입력하세요...    ] [보통▾] [추가] │  ← 입력 영역
├──────────────────────────────────────┤
│  [전체] [진행 중] [완료]               │  ← 필터 탭
├──────────────────────────────────────┤
│  ☐ ● 기획서 초안 작성             [×] │
│  ☐ ● 팀 회의 준비                 [×] │  ← 할일 목록
│  ☑ ● ~~메일 답장~~                [×] │
├──────────────────────────────────────┤
│  남은 할일 2개        [완료 항목 지우기] │  ← 푸터
└──────────────────────────────────────┘
```

### 6.2 컴포넌트 정의

| 컴포넌트 | 구성 요소 | 동작 |
|---|---|---|
| Header | 제목, 날짜, 테마 토글 | 날짜는 로드 시 + 자정 경과 시 갱신 |
| ProgressBar | 바, 텍스트 | 할일 0개면 숨김 또는 "0 / 0" |
| CarryOverBanner | 메시지, 가져오기/닫기 버튼 | 가져오기 시 어제 미완료 항목을 오늘로 복사 |
| TodoInput | 텍스트 입력, 우선순위 선택, 추가 버튼 | 로드 시 자동 포커스, 추가 후 입력창 비우고 포커스 유지 |
| FilterTabs | 3개 탭 | 선택된 탭 강조, 선택 상태 저장 |
| TodoList / TodoItem | 체크박스, 우선순위 점, 텍스트, 삭제 버튼 | 정렬: 미완료 먼저 → 우선순위 높은 순 → 생성 순 (드래그 정렬 도입 시 order 우선) |
| Footer | 남은 개수, 일괄 삭제 버튼 | 완료 항목 없으면 버튼 비활성 |
| EmptyState | 안내 문구 | 필터별 문구 다름 ("완료한 할일이 아직 없어요" 등) |

### 6.3 디자인 가이드
- 색상 토큰 (CSS 변수로 정의, 다크 모드에서 재정의)
  - `--bg`, `--surface`, `--text`, `--text-muted`, `--border`, `--accent`
  - 우선순위: `--prio-high`(빨강 계열), `--prio-mid`(주황 계열), `--prio-low`(회색 계열)
- 폰트: 시스템 폰트 스택 (`-apple-system, "Segoe UI", "Malgun Gothic", sans-serif`)
- 모서리 둥글기 8px, 기본 간격 단위 8px
- 체크 시 짧은 전환 애니메이션(150ms), `prefers-reduced-motion` 시 제거

## 7. 데이터 설계

### 7.1 Todo 객체

```ts
interface Todo {
  id: string;          // crypto.randomUUID()
  text: string;        // 1~100자
  done: boolean;
  priority: "high" | "mid" | "low";
  date: string;        // "YYYY-MM-DD" (로컬 시간 기준), 이 할일이 속한 날
  createdAt: number;   // epoch ms
  completedAt: number | null;
  order: number;       // 드래그 정렬용 (P2)
}
```

### 7.2 저장 구조 (localStorage)

| 키 | 값 | 설명 |
|---|---|---|
| `todayTodo.v1.todos` | `Todo[]` (JSON) | 전체 할일 (날짜 필드로 구분) |
| `todayTodo.v1.prefs` | `{ filter, theme, dismissedCarryOver: "YYYY-MM-DD" }` | 사용자 설정 |

- 키에 버전(`v1`)을 붙여 이후 구조 변경 시 마이그레이션 가능하게 한다.
- 보관 기간: 30일이 지난 할일은 로드 시 자동 정리한다.
- JSON 파싱 실패 시 기존 값을 `todayTodo.v1.todos.backup`으로 옮기고 빈 목록으로 시작한다.

### 7.3 날짜 처리 규칙
- "오늘"은 사용자 브라우저의 **로컬 시간** 기준 `YYYY-MM-DD`.
- 화면에는 `date === today`인 항목만 표시한다.
- 탭이 열린 채 자정을 넘기면(1분 간격 확인 또는 `visibilitychange` 시 확인) 오늘 날짜를 갱신하고 화면을 다시 그린다.
- 이월: 가장 최근 과거 날짜의 미완료 항목을 새 id로 복사하고 `date`를 오늘로 바꾼다. 원본은 그대로 둔다.

## 8. 상태 관리 및 모듈 구조

### 8.1 파일 구조 (예정)

```
todolist/
├── prd.md          # 본 문서
├── index.html      # 마크업
├── style.css       # 스타일 (토큰, 레이아웃, 다크모드)
└── app.js          # 로직
```

### 8.2 app.js 내부 구조

단방향 흐름: **사용자 이벤트 → 액션 함수 → state 변경 → save() → render()**

| 영역 | 함수 (예시) | 역할 |
|---|---|---|
| Storage | `load()`, `save()` | localStorage 읽기/쓰기, 예외 처리 |
| State | `state = { todos, filter, today, theme }` | 단일 상태 객체 |
| Actions | `addTodo(text, priority)`, `toggleTodo(id)`, `editTodo(id, text)`, `deleteTodo(id)`, `clearCompleted()`, `carryOver()`, `setFilter(f)` | 상태 변경만 담당 |
| Selectors | `todayTodos()`, `visibleTodos()`, `progress()` | 파생 데이터 계산 |
| View | `render()`, `renderItem(todo)` | DOM 갱신 (목록은 전체 재렌더, 이벤트는 위임) |
| Utils | `todayKey()`, `formatDate()` | 날짜 유틸 |

- 이벤트는 목록 컨테이너에 **이벤트 위임**으로 한 번만 등록한다.
- 항목 요소에 `data-id`를 두어 어떤 할일인지 식별한다.

## 10. 예외 및 엣지 케이스

| 상황 | 처리 |
|---|---|
| 공백만 입력 | 추가하지 않음, 입력창 흔들림 등 가벼운 피드백 |
| 100자 초과 | 입력 제한(maxlength) + 남은 글자 수 표시 |
| 같은 내용 중복 | 허용 (사용자 의도일 수 있음) |
| localStorage 불가 | 메모리로만 동작, 상단에 "이 브라우저에서는 저장되지 않아요" 안내 |
| 저장 용량 초과 | 오래된 기록부터 정리 후 재시도, 실패 시 안내 |
| 여러 탭 동시 사용 | `storage` 이벤트로 다른 탭 변경 사항 반영 |
| 시스템 시간 변경 | 다음 확인 주기에 오늘 날짜 재계산 |

## 11. 인수 조건 (Acceptance Criteria)

MVP(P0 + P1) 완료 기준:

- [ ] `index.html`을 열면 오늘 날짜와 빈 상태 안내가 보인다.
- [ ] 할일을 입력하고 Enter를 누르면 목록에 추가되고 입력창이 비워진다.
- [ ] 체크박스를 누르면 취소선이 생기고 진행률이 즉시 갱신된다.
- [ ] 삭제 버튼을 누르면 항목이 사라지고 진행률이 갱신된다.
- [ ] 새로고침 후에도 목록·완료 상태·필터 선택이 유지된다.
- [ ] 더블클릭으로 수정, Esc로 취소가 된다.
- [ ] 필터 탭에 따라 해당 항목만 보인다.
- [ ] 다음 날 열면 목록이 비어 있고, 어제 미완료 항목 가져오기 배너가 뜬다.
- [ ] `<script>alert(1)</script>`를 입력해도 텍스트로만 표시된다.
- [ ] 360px 폭에서 가로 스크롤 없이 모든 기능을 사용할 수 있다.
- [ ] 마우스 없이 키보드만으로 추가·완료·삭제가 가능하다.
